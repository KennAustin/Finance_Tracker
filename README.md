## 💰 Finance Tracker

Finance Tracker adalah aplikasi web sederhana yang memungkinkan pengguna untuk mencatat dan mengelola pemasukan serta pengeluaran mereka. Aplikasi ini dirancang untuk membantu pengguna dalam memantau keuangan pribadi dengan antarmuka yang intuitif dan responsif.

## 🚀 Fitur Utama

- ➕ Menambahkan transaksi pemasukan atau pengeluaran.
- 🗑️ Menghapus transaksi yang tidak diperlukan.
- 📋 Menampilkan daftar transaksi yang telah dicatat.
- 💾 Penyimpanan data menggunakan Local Storage untuk mempertahankan data antar sesi.
- 🎨 Antarmuka pengguna yang responsif dan mudah digunakan.

## 🛠️ Teknologi yang Digunakan

- **HTML**: Struktur halaman web.
- **CSS**: Styling dan tata letak halaman.
- **JavaScript**: Logika aplikasi dan interaksi pengguna.

## 📂 Struktur Proyek

Finance_Tracker/ 
├── index.html

└── README.md

## 🔧 Cara Menggunakan

1. Buka `index.html` di browser Anda.
2. Masukkan deskripsi dan jumlah transaksi pada kolom input, lalu tekan Enter atau klik tombol "Tambah".
3. Transaksi akan ditambahkan ke daftar dengan opsi untuk menghapusnya.
4. Data transaksi akan disimpan di Local Storage, sehingga tetap tersedia saat halaman dimuat ulang.

## 📌 Catatan

- Pastikan browser Anda mendukung Local Storage untuk menyimpan data transaksi.
- Aplikasi ini dirancang untuk penggunaan pribadi dan tidak memerlukan backend atau database eksternal.
